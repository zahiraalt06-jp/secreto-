EL ÚLTIMO SECRETO DE CARLOS — AVENTURA DE PLATAFORMAS

Esta versión sustituye las pruebas de pulsar botones por una aventura de plataformas 2D jugable.

ARCHIVOS:
- index.html
- style.css
- script.js
- mini_yo.png
- LEEME.txt

CONTRASEÑA: NAVIDAD23

CÓMO SE JUEGA:
- Ordenador: flechas izquierda/derecha o A/D para moverse; flecha arriba, W o espacio para saltar.
- Móvil: mantén pulsadas las flechas de la pantalla para moverte y pulsa SALTAR.
- Recoge las tres estrellas de cada mundo y llega a la puerta.
- Evita los obstáculos; tienes tres vidas.
- Al completar el mundo aparece una pregunta o el mensaje Morse que desbloquea el siguiente.

MUNDOS:
1. El pueblo nevado — recuerdo de Cádiz.
2. El bosque encantado — los ojos de Carlos.
3. El reino de los dulces — brownies y galletas.
4. La montaña de los secretos — único código Morse: AMORSIIIN.
5. El castillo helado — el mensaje del osito.

PARA PUBLICAR:
Descomprime este ZIP y sustituye en el repositorio de GitHub los cinco archivos anteriores. Mantén GitHub Pages en la rama main y carpeta raíz.

NOTAS:
- El progreso de la aventura se reinicia si recargas la página.
- La contraseña es una pantalla de entrada temática, no seguridad real.
- El juego usa un canvas 2D con gravedad, salto, plataformas, cámara lateral, estrellas coleccionables, obstáculos, vidas y controles táctiles/teclado.
